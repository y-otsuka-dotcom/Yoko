# Yoko — 30日間の英語学習

1日90分の学習メニュー、質問音声、振り返りをまとめた静的なWebサイトです。
スマートフォンとパソコンの両方で使えます。

## できること

- 30日分の学習メニューを一覧・週別で確認する。
- 日ごとの教材リンク、見る範囲、90分の手順、日本語付きの練習問題を開く。
- 英語の質問を端末の読み上げ機能で聞き、答えの例をあとから開く。
- 質問の順番を変えて練習する。
- 完了した日、振り返り、1・10・20・30日目の確認結果をブラウザに保存する。
- 学習記録をテキストでダウンロードしたり、1日分をコピーしたりする。

記録は、このサイトを開いたブラウザの localStorage に保存します。
別の端末への同期、ログイン、コーチへの自動送信はありません。
ブラウザのデータを削除すると記録も消えるため、必要な記録はダウンロードしてください。
端末に英語音声がない場合や読み上げに非対応の場合は、画面の案内から別の再生方法を使えます。

## 開発する

Node.js 24 系を使用します。検証環境は Node.js 24.19.0 / npm 11.9.0 です。

```bash
cd /workspace/Yoko
npm ci
npm run dev
```

開発サーバーはこのマシン内のポート5173で動作します。
公開用ファイルを作るコマンドは次のとおりです。

```bash
npm run build
```

`dist/` に生成されます。この操作だけではインターネットには公開されません。

## GitHub Pagesで公開する

GitHub Pagesの公開元は **mainブランチの /docs フォルダー** とします。

1. `npm run build:pages` を実行して `docs/` を生成します。
2. ソースと `docs/` を一緒にコミットし、GitHubの `main` にプッシュします。
3. 初回だけ、GitHubの次の設定画面を開きます。

   https://github.com/y-otsuka-dotcom/Yoko/settings/pages

4. Source（ソース）で **Deploy from a branch（ブランチからデプロイ）** を選びます。
5. Branch（ブランチ）で **main**、フォルダーで **/docs** を選び、Save（保存）を押します。
6. GitHub側の公開処理が成功したことを確認し、表示された公開URLを開きます。

設定が完了した場合の標準URLは `https://y-otsuka-dotcom.github.io/Yoko/` です。
URLが存在するというだけでは公開成功とは判断せず、GitHubの成功表示と実際のページを確認してください。
リポジトリの公開範囲・契約によってPagesの利用条件が異なる場合は、GitHubに表示される案内を確認します。
リポジトリの公開範囲は自動では変更しません。

以後は、ソースを変更したら `npm run build:pages` を再実行し、変更した `docs/` も一緒にプッシュします。
`docs/` は自動生成物です。直接編集せず、`src/` を変更してください。
これはCodexの環境設定にあるPublishとは別の操作です。

## 検証する

```bash
npm test
npm run build
npm run test:e2e
```

`npm test` は30日分の時間・教材データ・学習記録の検証を行います。
`npm run test:e2e` は `docs/` を再生成し、公開時と同じ `/Yoko/` パスでブラウザテストを行います。
30日分の移動、週別表示、保存と復元、確認問題の並べ替え、音声APIへの入力、非対応時の案内、小さい画面での表示を検証します。
音声テストは読み上げAPIを模擬します。実端末のスピーカーからの音声再生は、端末の対応状況に依存します。

クラウド環境では既存の `/usr/bin/chromium` を使います。
別の環境では `npx playwright install chromium` でブラウザを導入するか、
`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` でインストール済みChromiumを指定してください。
サンドボックスがポートやブラウザ・テスト子プロセスの起動を制限する場合は、許可された実行権限のフローを使って検証します。

## 主なファイル

| ファイル | 役割 |
| --- | --- |
| `src/curriculum.js` | 30日分の学習内容、教材の使用範囲、時間配分 |

| `docs/` | GitHub Pagesで配信する公開用ファイル |

## 教材と掲載範囲

動画リンクはBritish Councilの「Checking understanding」です。
https://learnenglish.britishcouncil.org/skills/speaking/a1-speaking/checking-understanding

動画の使用範囲は、ユーザーが共有した公式教材のTranscriptを根拠にしています。
制作者による公式動画の直接再生や、現在の登録・課金条件の確認は未実施です。
動画全文は転載せず、教材へリンクし、短い練習表現と使用範囲を掲載しています。
各日の質問・返答例、時間配分、達成目安はこの計画のためのオリジナルです。

本人に向けた学習内容を掲載し、コーチ向けの個人評価や弱点の記録は公開ページに含めていません。
APIキーや秘密情報をソース、VITE_ から始まる環境変数、公開用ファイルへ入れないでください。
